📚 Calendar Planner Guide

🗓️ Getting Started

Create Categories: Click "Manage Plan" → "Add New" to create event categories (e.g., Work, Personal, Travel)
Add Dates: Each category can have multiple date ranges. Use the date picker or type dates manually

🎨 Customization

Colors & Emojis: Personalize each category with custom colors and emojis
Drag & Drop: Reorder your categories by dragging the stat cards or items in the category list
Themes: Switch between Light and Dark themes using the theme toggle button

📊 Smart Features

Exclude Holidays: Toggle to exclude weekends and public holidays from counts
Statistics: View day counts and filter calendar by category using the stat cards
Year Navigation: Browse different years with arrow buttons, use "Today" to return to current date

📝 Text Import

Bulk Import: Paste schedule text and let the smart parser extract dates and categories automatically
Supported Formats: Works with various date formats (DD/MM/YYYY, DD Month, date ranges)

👥 Group Categories

Create Groups: Combine multiple categories to see overlapping dates (when everyone is active together)
Team Planning: Perfect for coordinating schedules, finding common working days, or planning meetings

🔄 Advanced Features

Undo/Redo: Accidentally deleted something? Use Ctrl+Z or the undo toast that appears
Search & Filter: Find categories quickly using the search function in category management
PWA Support: Install as an app on your device for offline access and native experience

💡 Pro Tips

  • Double-click any calendar day to quickly add events
  • Use date ranges like "20th Oct - 24th Oct" for multi-day events
  • Create a "Public Holidays" category to automatically exclude holidays from other categories
  • Group categories show intersections - use for team coordination
  • All data is stored locally in your browser - completely private
