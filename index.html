📚 Calendar Planner Guide

🚀 Quick Actions

Floating Menu: Tap the round button at bottom‑left to open quick actions with labels
Add / Manage: Create or edit categories; drag to reorder
Import: Import from text or a backup file
Export: One‑click backup from FAB or Manage → Export
Toggle Stats: Show or hide the stat cards; your choice is remembered
Theme: Switch Light/Midnight; use Gradient Themes for colorful month headers
Help: Open this guide any time

🗓️ Getting Started

Create Categories: Manage Categories → Add New (emoji + color)
Add Dates: Use the date picker or type ranges manually

🗺️ Navigation

Month / Year: Use the segmented toggle to switch views
Today: Centers the actual in‑month date cell (not the faded spillover)
Drag & Drop: Reorder categories via stat cards or list — optimized for touch
Themes: Switch Light/Midnight instantly

📝 Import & Backup

Text Import: Paste schedule text — the parser auto‑creates categories and dates
Backup Restore: Replace, Merge (skip duplicates), or Merge (rename duplicates)
Formats: Understands many date formats (e.g., 25 Dec, 25/12/2025, 1–5 Jan)

👥 Group Categories

Create Groups: Combine multiple categories to see overlapping dates (when everyone is active together)
Team Planning: Perfect for coordinating schedules, finding common working days, or planning meetings

🔄 Advanced

Undo: Use Ctrl+Z or the undo toast
Search & Sort: Find categories fast; sort by name, usage, or recent
PWA: Install to your device; works offline after first load

💡 Pro Tips

  • Long‑press is optimized for touch — drag works without opening a context menu
  • Double‑click a day to add quickly; use ranges like “20 Oct – 24 Oct”
  • Create a “Public Holidays” category once; others can exclude its days automatically
  • Stat cards act as filters — click to focus a category, click Overview to reset
  • All data stays on your device — no accounts, no tracking
